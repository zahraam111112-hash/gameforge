    How it works

    1 · Observe

    A critic pass plays the current build with scripted bots, collects frame data, deaths, stuck points, session length, then reads the devlog and the open issues.

    2 · Decide

    A planner turns observations into a small, ranked set of improvements with an explicit rationale — story, graphics, gameplay, audio, netcode.

    3 · Build

    Several builders work in parallel in isolated worktrees. Every change must compile and pass the unit + bot simulation suite before it can merge.

    4 · Verify & ship

    A verifier replays seeds in a real headless browser, checks the visuals, and only then tags a stable version, archives it and updates this site.
